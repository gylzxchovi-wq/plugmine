SolhavenNPC 1.0.0 — Paper 1.21.4
================================

Содержимое ZIP:
- Полный исходный проект Maven.
- Зависимость Paper API 1.21.4.
- Зависимость ProtocolLib 5.4.0 (не включена в итоговый JAR).
- Настройки скина и отображения NPC.

ТРЕБОВАНИЯ
----------
1. Сервер Paper 1.21.4.
2. Java 21.
3. ProtocolLib 5.4.0, установленный в папку plugins сервера.
   ProtocolLib 5.4.0 заявляет поддержку Minecraft 1.21.4–1.21.8.
4. Maven 3.9+ для сборки проекта.

СБОРКА JAR
----------
1. Распакуй SolhavenNPC.zip.
2. Открой папку SolhavenNPC.
3. В адресной строке проводника напиши cmd и нажми Enter.
4. В открывшемся окне выполни:
       mvn clean package
5. Готовый файл появится здесь:
       target/SolhavenNPC.jar
6. Скопируй SolhavenNPC.jar и ProtocolLib.jar в папку plugins сервера.
7. Перезапусти сервер.

НАСТРОЙКА СКИНА
---------------
После первого запуска открой:
       plugins/SolhavenNPC/config.yml

Измени:
       skin-name: "Notch"

Вместо Notch укажи точный ник Minecraft-аккаунта, чей официальный скин нужно скопировать.
Перезапусти сервер или пересоздай NPC после изменения настройки.

КОМАНДЫ
-------
/create NPC — создать NPC на позиции ног администратора.
/del NPC    — удалить NPC, на которого направлен прицел (до 6 блоков).

Обе команды доступны только OP. Других команд плагин не регистрирует.

ПОВЕДЕНИЕ
---------
- NPC — фейковый игрок, отображаемый через сетевые пакеты, а не житель.
- Не является настоящим подключённым игроком и не имеет серверной физической сущности.
- Поэтому его нельзя убить, оттолкнуть, сдвинуть поршнем или повредить взрывом.
- Пакеты атаки/взаимодействия с ID NPC отменяются.
- NPC сохраняются в config.yml и появляются после перезапуска.
- В пределах 50 блоков поворачивается к ближайшему игроку.
- Отображается игрокам в пределах view-distance.

ВАЖНО
-----
Это исходный проект для сборки. В этой среде Maven не установлен, поэтому готовый
SolhavenNPC.jar здесь не был собран и не заявляется как проверенный бинарный файл.
После сборки на ПК проверь запуск на тестовом сервере Paper 1.21.4 перед установкой
на основной сервер.

Если скин не загружается, проверь:
- правильность ника;
- доступ сервера к Mojang API;
- что сервер работает в online-mode (для получения официального профиля).
